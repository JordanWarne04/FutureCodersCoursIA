# 🚀 Ouvrir ton projet dans Google Colab

Google Colab te permet d'écrire et d'exécuter du code Python directement dans ton navigateur, sans rien installer !

### 1. Ouvre Google Colab

Va sur [Google Colab](https://colab.research.google.com/) et connecte-toi avec ton compte Google.

### 2. Importe ton projet 📂

1. Clique sur **Fichier → Importer un notebook**.
2. Sélectionne le fichier `project_base.ipynb` sur ton ordinateur.
3. Attends que ton notebook s'ouvre.

### 3. Exécute ton code ▶️

- Clique sur le bouton **▶️** à gauche d'une cellule pour exécuter son code.
- Lors de la première exécution, Google Colab peut te demander de te connecter à un environnement Python.
- Tu peux modifier le code et le relancer autant de fois que tu veux.
- Pour exécuter toutes les cellules : **Exécution → Tout exécuter**.

### 4. Sauvegarde ton travail 💾

Tu peux enregistrer ton notebook dans Google Drive.

Pour récupérer ton projet sur ton ordinateur : **Fichier → Télécharger → Télécharger le fichier .ipynb**.

**🎉 C'est parti ! Amuse-toi à expérimenter avec ton projet d'IA !**
